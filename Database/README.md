#Open-access Eye tracking Database

Signals from eye tracker used in this paper are freely available at the Zenodo repository DOI

## Description
The database consists of EGGs recorded in 20 healthy volunteers on three channels (CH1, CH2, CH3) and two states (fasting and postprandial). Sample rate is set at fs = 100 Hz. 

## Naming convention
subject'sID _ type of recording (fasting / postprandial).txt

An example:

ID9_fasting.txt (subject ID9 in fasting state)

Every .txt file is presented in 2400 x 3 format (number_of_samples x number_of_channels)

If you find these signals useful for your own research, please cite the relevant papers and dataset as:

Popović, N.B., Miljković, N. and Popović, M.B., 2020. Three-channel surface electrogastrogram (EGG) dataset recorded during fasting and post-prandial states in 20 healthy individuals [Data set]. Zenodo, doi: 10.5281/zenodo.3730617.
